# Geeklog plugin compatibility directory

> **Baseline: Geeklog 2.2.2** · Updated: 2026-10-24 · [Browse the interactive directory](https://hostellerie.github.io/Plugin-Compatibility-List/) (requires GitHub Pages to be enabled).

A maintained inventory of the [Geeklog-Plugins](https://github.com/Geeklog-Plugins) organization, the bundled Geeklog core plugins and additional public projects from [hostellerie](https://github.com/hostellerie). Historical matrices for older Geeklog versions have been retired from the main page (available in Git history).

**Important:** A repository's existence, an available release or a stated minimum Geeklog version **does not prove compatibility**. Do not treat an untested plugin as confirmed compatible with 2.2.2. PHP and database support also require separate verification.

**PHP support:** “Reported” means the maintainer reports PHP 5.6 and PHP 8.1 compatibility for recently worked-on plugins; the precise release/environment is not independently tested in this directory. “?” means not yet verified. PHP 7.4 or PHP 8.0 support must not be inferred automatically from tests on PHP 5.6 and PHP 8.1. Core compatibility and plugin release compatibility are separate claims.

### Compatibility verification checklist

For every non-core plugin, test installation or upgrade on Geeklog 2.2.2, key admin and public screens, permissions, uninstall behaviour, PHP 8.1 / 8.2 / 8.3 warnings, and supported database engines. Record the **tested plugin tag/commit, environment, test date, tester and evidence** before upgrading the status to Verified. A declared minimum version is not a runtime test.

### Scope and maintenance

- Public Geeklog plugin projects discovered under Geeklog-Plugins are included **except** organization infrastructure/assets (`.github`, `artwork`, `memorandum`, `language-audit`). Tools and infrastructure are not installable plugins.
- Only explicitly public, plugin-related repositories from hostellerie absent from Geeklog-Plugins are listed separately. Private repositories are excluded. Additional candidate repositories are listed and may be experimental or non-installable; inclusion is **not** an endorsement of release readiness.
- Only plugin projects are eligible; `plugin-toolkit` and other tooling are not entries. Plugins mirrored between the two accounts appear once, with Geeklog-Plugins as the canonical link.
- Core plugin versions must be read from the Geeklog 2.2.2 distribution before publishing precise version claims.
- To update the catalog, edit `README.md` and the `catalog` data in `index.html`; future automation should use GitHub API metadata without automatically changing compatibility verdicts.

## Contribute a compatibility report

Open an [issue](https://github.com/hostellerie/Plugin-Compatibility-List/issues/new) with plugin, tested version/commit, Geeklog version, PHP version, database, test results and reproducible evidence. Reports are reviewed before a Verified label is granted.

### Privacy and inclusion policy

Never import the authenticated user's full repository list into this **public** catalog without checking `visibility === public` per repository. Include only installable Geeklog plugins, and never private repositories, tools, themes, or unrelated projects. Repository visibility must be checked again before publication.
