What do these labels mean?

Bundled: included in the Geeklog core distribution. Not verified: no recent 2.2.2 test recorded. Development / review: project requires maturity and compatibility review. Legacy concern: historically documented incompatibility or outdated code that requires new testing.

¹ Latest GitHub Releases checked 24 October 2026 for 33 repositories; a dash means no latest release confirmed.
